# Minimarket Inventario

# 

# CRUD de inventario de productos para un minimarket, desarrollado con C# y Windows Forms.

# Proyecto de la Tarea 3 de Programación III (Uso de Git y Git Flow).

# 

# Autor: Jonh Encarnacion

# 

# Tecnologías

# \- C# y .NET 9

# \- Windows Forms

# \- SQLite (paquete Microsoft.Data.Sqlite)

# 

# Requisitos

# \- Windows

# \- Visual Studio 2022 (o superior) con la carga de trabajo de escritorio de .NET

# \- SDK de .NET 9

# 

# Base de datos

# El proyecto incluye el archivo `MinimarketInventario/minimarket.db` con productos de ejemplo.

# Se copia automáticamente junto al programa al compilar. Si el archivo no existe,

# la aplicación crea la tabla `Productos` al iniciar.

# 

# Funcionalidades

# \- Registrar productos (código único, nombre, categoría, precio y stock)

# \- Listar productos en una tabla

# \- Editar un producto seleccionado

# \- Eliminar un producto con confirmación

# 

# Flujo de ramas (Git Flow)

# Ramas principales: `main`, `develop` y `qa`.

# 

# Ramas de trabajo (cada una integrada a `develop`, `qa` y `main` mediante Pull Requests):

# \- `feature/database-setup`

# \- `feature/create-record`

# \- `feature/read-list`

# \- `feature/update-record`

# \- `feature/delete-record`
